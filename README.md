# Video-Maker

AI-independent, browser-only programmatic video editor.

## Current MVP
- Import a Video-Maker project as JSON or ZIP.
- Paste JSON generated by ChatGPT, Claude, Gemini, or another AI.
- Edit scene text and durations in the browser.
- Preview the composition with Remotion Player.
- Render MP4 locally in the browser with Remotion Web Renderer (WebCodecs).

No AI API key, backend, or account is required.

## Requirements
- Node.js 20+
- A modern browser with WebCodecs support (Chrome 94+, Firefox 130+, Safari 26+).
- A browser with enough memory for the selected video resolution and duration.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Import format
Import a `.json` file or a `.zip` containing `project.json` at its root. The project JSON can contain scenes inline or reference JSON files under `scenes/`.

See `public/example-project.json` for the format.

## Supported scene types
- `title`
- `text`
- `stat`
- `bullets`
- `outro`

AI-generated React/JavaScript is not executed. Use the portable JSON scene format instead: it is safer, easier to validate, and works with any AI provider.

## Browser rendering notes
MP4 rendering uses `@remotion/web-renderer` and the browser's WebCodecs implementation. Rendering is local to the browser; large projects can require substantial RAM/GPU resources. The app checks browser support before export.
